# MC Financial review, November 19, 2026

Reviewed main at 7daf6f2 and prepared targeted UI recovery and accessibility fixes.

## Scope and evidence

The source inventory contains 46 page routes and 92 API handlers. Reviewed the shared admin and member layouts, navigation and UI controls, member home, payments, history, loan agreements and card flows, the authentication boundary, Wallet endpoint, and existing browser and authorization coverage. Earlier theme and portal changes through PR #43 are present in main.

This is a source review with local compilation checks. Production data, server configuration, real payment providers, Apple certificates and the complete signed-in UI have not been verified in this environment. Chromium launch failed here, and database-backed tests require a separate PostgreSQL test database.

## Findings addressed

| Priority | Finding | Change |
| --- | --- | --- |
| High | Home, History and Membership card accept failed HTTP responses as page data, and rejected requests can leave an endless skeleton. | Shared abortable read hook, status checks, visible failure state and in-place retry. |
| High | Payment-page loading can reject without ending the loading state. Failed HTTP responses can be interpreted as configuration. | Explicit status checks, retry state, and loading cleanup. |
| High | Interrupted checkout or agreement requests leave their action disabled. | Catch failures, restore controls in finally, and instruct members to check the recorded result before resubmitting. |
| Medium | The ordinary Next.js error boundary renders another html/body inside the root layout. | Render an alert section within the existing document. |
| Medium | Keyboard users must traverse navigation before reaching workspace content. | Visible-on-focus skip link and a focusable main target in both workspaces. |
| Medium | Shared form errors are visually adjacent but not associated with their controls. | Invalid state, error descriptions, preserved caller descriptions, and announced errors for inputs, selects and textareas. |

The browser suite gains a recovery check that fails four member endpoints, retries after restoring the endpoint, and checks that loading ends without horizontal overflow.
